# Support

Read [the troubleshooting runbook](wiki/troubleshooting.md), [the authentication guide](wiki/authentication.md), and [release readiness](docs/RELEASE-READINESS.md) before opening an issue.

When reporting a bug, include:

- Operating system and Python version
- Output of `legends-gohighlevel doctor`
- Exact command and sanitized stderr JSON

Never include `GHL_PIT`, `GHL_ACCESS_TOKEN`, customer email addresses, phone numbers, or private sub-account dumps.
